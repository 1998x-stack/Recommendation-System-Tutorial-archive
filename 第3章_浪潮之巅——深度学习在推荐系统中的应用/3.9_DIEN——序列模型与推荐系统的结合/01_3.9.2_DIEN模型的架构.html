DIEN 模型的架构

DIN 只看用户历史行为与候选广告的相关性，却不追踪兴趣本身如何随时间演变。DIEN（Deep Interest Evolution Network）由阿里巴巴提出，在 DIN 基础上加入序列模型：先用 GRU 从行为序列中抽取兴趣状态，再用带注意力的 AUGRU 模拟与当前广告相关的兴趣进化。它把“用户兴趣”从一张静态快照，变成一个会演化的过程。

兴趣进化网络三层

DIEN 的整体架构沿用了 DIN 的骨架：输入层、Embedding 层、连接层、多层全连接与输出层。它真正的创新是一个叫兴趣进化网络的模块，模拟用户兴趣的动态变化。

这个模块自下而上有三层：行为序列层把原始 ID 行为序列变成 Embedding 序列；兴趣抽取层用 GRU 模拟兴趣迁移、抽出兴趣状态；兴趣进化层在兴趣抽取层基础上加入注意力，模拟与当前目标广告相关的兴趣进化。

行为序列层：把 ID 序列变成向量序列

推荐的原始输入是用户的 ID 类行为序列，如点击、浏览、购买的物品 ID。它们是高维稀疏的离散符号，神经网络难以直接处理。

行为序列层用 Embedding 把这些 ID 映射为低维稠密的向量，得到一条Embedding 行为序列。这一步与 DIN 共享同一套思路：行为序列中每个时刻对应一个向量，为后续的序列模型提供按时间排列的输入。

兴趣抽取层：用 GRU 模拟兴趣迁移

兴趣抽取层采用 GRU（Gated Recurrent Unit，门控循环单元）来模拟用户兴趣的迁移过程。GRU 通过门控机制控制信息流动：重置门决定“保留多少历史信息”，更新门决定“当前候选状态写入多少”。相比普通 RNN，门控能有效缓解梯度消失；相比 LSTM，GRU 参数更少、训练更快。

逐时刻地，GRU 根据当前行为向量与上一时刻的兴趣状态，算出新的兴趣状态向量 ht。整个序列跑完后，就得到一串“兴趣状态”轨迹，它刻画了用户逐时逐刻的兴趣表示。

兴趣进化层：AUGRU 与注意力

光有兴趣状态还不够——推荐面对的是具体的目标广告。不同广告下，同一段历史行为里相关的部分不同。兴趣进化层在兴趣抽取层基础上引入注意力，用 AUGRU（GRU with Attentional Update Gate，带注意力更新门的 GRU）模拟与当前目标广告相关的兴趣进化。

AUGRU 的关键是把注意力得分乘到 GRU 的更新门上：

u~t=at⋅ut

其中 at 是注意力得分，它由当前兴趣状态 ht 与目标广告向量的匹配程度算出；ut 是 GRU 原本的更新门。at 越大，对应时刻的兴趣状态越多地被写入。这样，与当前广告相关的兴趣被放大、无关的被压制，兴趣状态的更新随目标而变化。

输出与优势

兴趣进化网络输出的兴趣表示，与其他特征（用户、广告、上下文）拼接后，送入多层全连接，最后由输出层给出点击概率。

相比传统推荐模型，DIEN 的优势在于：

  • 捕捉兴趣的动态变化：用序列模型加注意力追踪兴趣随时间的演变，提高推荐的准确性与相关性。
  • 更强的表达能力：GRU 与 AUGRU 使模型在处理行为序列时能表达更复杂的时序模式。
  • 训练效率较高：GRU 比 LSTM 参数更少、训练更快；AUGRU 的注意力机制让隐藏状态更新更高效。

小结

DIEN 可以概括为“在 DIN 上再加一个兴趣进化网络”：行为序列层把 ID 序列变成 Embedding 序列；兴趣抽取层用 GRU 抽出兴趣状态；兴趣进化层用 AUGRU 把目标广告的注意力得分乘进更新门，让兴趣朝与当前广告相关的方向演化。它把“用户兴趣”从一张静态快照，变成一个随时间与目标变化的动态过程。
