NeuralCF 模型的结构

NeuralCF 把矩阵分解里那个“用户向量与物品向量做内积”的操作，换成了一个多层神经网络。用户和物品的 Embedding 先拼在一起，再经多层全连接做非线性交叉，最后输出预测评分。它保留了协同过滤的骨架，却把表达能力从线性拉升到非线性。

用网络替代内积

NeuralCF（Neural Collaborative Filtering）由新加坡国立大学的研究者于 2017 年提出。它要解决的是传统矩阵分解的一个先天限制：用户向量与物品向量之间只做一次内积，这是一种线性运算，只能表达用户与物品之间简单、固定的交互关系。

NeuralCF 的思路是：保留“用户 Embedding + 物品 Embedding”的协同过滤骨架，但把两者的“互操作层”换成可替换的模块。既可以保留内积（此时退化为带权的广义矩阵分解），也可以把两个向量拼接后送进多层感知机（MLP）做非线性交叉。一个统一的框架，就同时覆盖了线性和非线性的交互方式。

Embedding 层：用户与物品的共享表示

模型的入口是两个 Embedding 层：用户 Embedding 层把用户 ID 映射为一条稠密向量，物品 Embedding 层把物品 ID 映射为一条同样维度的稠密向量。它们就相当于矩阵分解里的用户隐向量与物品隐向量。

这两层起到两个作用：一是降维——把高维稀疏的 one-hot ID 压成低维稠密向量，降低计算复杂度；二是表示——让兴趣相似的用户、被相似人群喜欢的物品在向量空间中靠近，把协同过滤的信号编码进向量里。

隐层：从 GMF 到 MLP

两个 Embedding 之后，模型用一个可替换的“互操作层”把它们结合起来。最直接的做法是保留矩阵分解的内积（此时退化为广义矩阵分解 GMF）；NeuralCF 的贡献则是提供另一种做法：把两个向量拼接后送入多层感知机：

h0=[pu;qi],hl=ReLU(Wlhl−1+bl)

其中 pu、qi 分别是用户与物品的 Embedding 向量，[· ; ·] 表示向量拼接。多层全连接加上 ReLU 等非线性激活，使模型能捕捉用户与物品之间的高阶特征交互，这是单次内积做不到的。层数越多，交互的阶数越高，表达能力也越强。

Scoring 层：输出预测评分

网络的最后一层把隐层的输出经过一个激活函数（如 sigmoid）变成最终的预测评分或点击概率。损失函数根据任务选择：回归式的评分预测常用均方误差（MSE），而点击率预估类任务常用交叉熵损失。

因为有 Embedding 与多层网络，整个模型可以端到端训练：通过反向传播，用户向量、物品向量与各层参数一起被优化，不需要为“如何交叉”人工设计特征。

优势与局限

NeuralCF 的价值和它的边界都很清楚。下表按几个方面归纳（整理自本仓讲义）：

方面优势局限
模型架构互操作层可任意替换、可拼接，具备广义矩阵分解特点依赖协同过滤思想，特征单一，未引入更多类型特征
表达能力用多层网络引入非线性，可捕捉高阶特征交互模型复杂度较高，需要更多数据与更长训练才能收敛
端到端训练自动优化参数与交叉方式，避免繁琐的人工特征工程训练与推断需较多计算资源，实时场景可能不够友好
数据稀疏向量表示能捕捉用户与物品的潜在特征用户历史行为稀疏时推荐效果会受影响
过拟合结构可伸缩，适应不同场景网络较深时易过拟合，需正则化手段

小结

NeuralCF 的结构可以概括为“同一对 Embedding，可替换的互操作层”：

  • Embedding 层：把用户 ID、物品 ID 变成稠密向量，相当于学出用户隐向量与物品隐向量。
  • 互操作层：保留内积就是广义矩阵分解（GMF）；拼接后过 MLP 则是非线性、高阶的特征交叉。
  • Scoring 层：激活输出预测评分，端到端训练。

它的意义在于把“矩阵分解”从固定的内积形式，扩展为一个可以把不同互操作层拼在一起的框架。局限也很明确：它仍然只在用户与物品两个 ID 上做文章，没有引入上下文、属性等更多类型的特征；用户行为稀疏时仍然困难。
