Deep Crossing 模型的网络结构

Deep Crossing 是微软 2016 年提出的推荐模型，用来解决大规模稀疏特征下的自动特征交叉。它把流程拆成四层：Embedding、Stacking、Multiple Residual Units、Scoring——稀疏特征先被稠密化，再拼接，再用残差单元自动做高阶交叉，最后由逻辑回归输出点击率。

四层结构总览

Deep Crossing 的设计目标，是让模型自己完成传统推荐系统中需要人工设计的特征交叉。它的输入是大量的类别型特征（如用户 ID、物品 ID、查询词等）与少量数值型特征；输出是点击率预估。

整条链路自下而上分为四层：Embedding 层把稀疏的类别型特征映射为稠密向量；Stacking 层把各路 Embedding 与数值特征拼接成一条长向量；Multiple Residual Units 层用多层残差单元自动学习特征间的高阶交互；Scoring 层做逻辑回归，输出点击概率。

Embedding 层：把稀疏特征变稠密

推荐系统的原始特征大多高度稀疏：一个类别型特征若有 1000 个取值，one-hot 之后就是一个 1000 维向量，其中只有一个元素为 1、其余全为 0。这样的向量维度高而信息密度低，直接送入神经网络既浪费参数又难以学习。

Embedding 层用一块可训练的Embedding 矩阵把稀疏向量映射为低维稠密向量。记输入 one-hot 向量为 x、Embedding 矩阵为 E，则得到的 Embedding 向量为 E · x（相当于按索引从 E 中取出对应的一行）。

v=E⋅x

训练时，Embedding 矩阵的参数与网络其余部分一起通过反向传播更新：预测误差的梯度会同时调整“查表得到的向量”和下游权重。这一层的价值有两方面：一是降维，大幅降低输入维度与计算开销；二是表示，让相似的类别在向量空间中靠近，捕捉类别型特征之间的潜在关系。

Stacking 层：把多路特征拼在一起

一个样本往往同时含有多个 Embedding 特征和若干数值型特征。Stacking 层的作用是把它们按顺序拼接成一个包含全部信息的长向量，作为后续网络的统一输入。

例如，一个样本含 3 个 Embedding 向量和 5 个数值型特征，若各 Embedding 向量维度为 d₁、d₂、d₃，则拼接后的维度为 d₁ + d₂ + d₃ + 5。拼接的好处是模型能同时利用类别型与数值型特征，并且可以灵活地接收任意数量、任意类型的特征。

Multiple Residual Units 层：自动做高阶交叉

这一层是 Deep Crossing 区别于普通 MLP 的关键。它把多个残差单元（Residual Unit）堆叠起来，每个单元内部是若干全连接层加非线性激活，并在输入与输出之间加一条跳跃连接（skip connection）。

yl=xl+ℱ(xl,Wl)

其中 xl 是第 l 层的输入，F(xl, Wl) 是经非线性变换后的特征表示，Wl 是该层可学习参数。堆叠多个残差单元后，模型能逐层学到更高阶、更复杂的特征交互关系。

为什么要把特征交叉交给残差网络？因为“阶数越高”往往意味着“网络越深”，而深网络容易出现梯度消失、难以训练。残差结构让输入可以直接沿跳跃连接流到输出，缓解了深层网络的训练困难，因此可以在不过度担心退化的情况下堆得足够深，让特征交叉的阶数随深度自然增长。

Scoring 层：输出点击概率

最后一层把残差层的输出经线性变换映射到 CTR 的概率空间，并用 sigmoid 把结果压到 [0, 1] 区间，作为点击率预估。训练目标通常采用交叉熵损失，通过反向传播优化全部参数。

这一层结构简单、计算高效，且优化目标（最小化交叉熵）与 CTR 预估的目标一致，因此能直接提升预测准确度。

小结

Deep Crossing 的四层可以概括为“稀疏→稠密→拼接→深二交叉→归一”：

  • Embedding 层：用可训练矩阵把高维稀疏类别特征压成低维稠密向量，降维并增强表示。
  • Stacking 层：把各路 Embedding 与数值特征拼接为一条长向量。
  • Multiple Residual Units 层：堆叠带跳跃连接的残差单元，在深网络中自动学习高阶特征交叉。
  • Scoring 层：逻辑回归 + 交叉熵，输出点击概率。

它的意义在于：把传统推荐系统依赖人工的特征交叉，变成了由网络自动完成的过程，从而在稀疏特征场景下得到更强的表达能力和更好的泛化性能。
