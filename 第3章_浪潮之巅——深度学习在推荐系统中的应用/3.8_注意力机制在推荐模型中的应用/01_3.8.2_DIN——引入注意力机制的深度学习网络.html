DIN——引入注意力机制的深度学习网络

把用户历史行为池化成一个固定长度的兴趣向量，等于把所有历史一视同仁。DIN 换了个思路：让候选广告去“唤醒”相关的那部分历史行为——用一个小网络算出注意力得分，对历史行为加权池化，得到一个随候选广告而变的兴趣向量。

一个固定兴趣向量的局限

推荐模型普遍会用用户的历史行为（点击、购买、浏览过的商品与店铺）来刻画兴趣。但同一串历史行为，面对不同候选广告时，真正相关的部分并不相同：一个买过奶粉的用户，看到奶瓶广告时“育婴”相关的行为最重要，看到奶粉广告时“母婴品牌”相关的行为才重要。

若先把所有历史行为 Embedding 后简单求和/平均，得到一个与候选广告无关的固定兴趣向量，这些“因广告而异”的差异就被抹平了。阿里巴巴提出的 DIN（Deep Interest Network）正是要解决这一点：用注意力机制对历史行为加权，权重由候选广告决定。

输入：历史行为序列 + 候选广告

DIN 的输入分两部分：

  • 用户历史行为序列：用户点击/购买的多个商品、店铺等，经 Embedding 后得到一组向量 e1, e2, …, en，其中 n 是历史行为数量。
  • 候选广告特征：广告对应的商品 ID、店铺 ID 等，经 Embedding 得到向量 a。

注意，历史行为是一串变长的序列，而不是一个汇总值——这是 DIN 能“因广告而异”地加权的前提。

注意力激活单元：让广告“唤醒”历史行为

DIN 用一个小的注意力激活单元（activation unit）计算每个历史行为与候选广告之间的注意力得分。先把两者拼接：

hi=[ei;a]

再经一个小型网络与激活函数得到得分，并对所有历史行为归一化，使权重之和为 1：

si=φ(Whi+b),αi=exp(si)∑j=1nexp(sj)

其中 φ 是激活函数（如 ReLU 或 tanh），W、b 是该单元的参数。αi 就是历史行为 i 在当前候选广告下的注意力权重：与广告越相关，权重越高。

说明：本仓同节讲义把这一步写作 αi=softmax(W hi+b)，并另列了一道归一化式。两者说的是同一件事：先由小网络算出一个原始得分，再对所有历史行为做归一化。本页把“得分”与“归一化后的权重”分开命名，以免混淆。

加权池化与输出层

拿到权重后，DIN 不再简单求和，而是先加权、再求和，得到与候选广告相关的用户兴趣向量：

u=∑i=1nαiei,v=[u;a]

最后把 v=[u;a] 送入多层全连接网络，得到预测 ŷ，再根据任务（如点击率预测）选用相应的损失函数（如交叉熵）训练。关键的差别就在第一步：同样的历史行为，面对不同候选广告会得到不同的 u，因而兴趣表示是动态的。

本仓同节讲义把 DIN 的优势归纳为三点：能捕捉用户对不同历史行为的不同关注程度（个性化兴趣捕捉）、对行为加权提高了推荐精准度、以及结构灵活便于按场景调整。讲义称其在阿里电商广告点击率预测上优于传统深度学习模型；具体数值未在本节给出，本页不追加未经核实的指标。

小结

DIN 用一个很轻的改动拆掉了“固定兴趣向量”的局限：用一个小网络根据 [ei;a] 算出注意力权重，对历史行为加权池化。输入仍是 Embedding，输出仍是多层网络，中间多了一步“因候选广告而异”的加权。这一“局部激活”思路直接启发了后续的 DIEN（用序列模型建模兴趣的演化）。
