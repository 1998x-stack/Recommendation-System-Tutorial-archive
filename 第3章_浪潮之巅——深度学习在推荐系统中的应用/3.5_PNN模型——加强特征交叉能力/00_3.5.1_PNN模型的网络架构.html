PNN 模型的网络架构

PNN（Product-based Neural Network）于 2016 年由上海交通大学的研究者提出。它在 Embedding 与全连接层之间插了一个“乘积层”，用内积或外积显式地构造特征之间的交叉向量，再交给后面的全连接网络。相比只靠 MLP 隐式交叉，乘积层让“哪些特征两两相乘”变得可设计、可解释。

乘积层：PNN 的核心

PNN 要解决的是 CTR 预估与推荐中的特征交叉问题。它在常见的“Embedding + 全连接”结构里插入了一个专门做交叉的乘积层（Product Layer），它不是等 MLP 去隐式地学交叉，而是直接把特征向量两两相乘（内积或外积）得到交叉信号。

整体信息流是：输入特征经 Embedding 变成若干向量；乘积层把这些向量两两做内积/外积，得到交叉向量；乘积层的输出与原始 Embedding 一起送入隐藏层做多层非线性变换；最后由输出层得到点击概率。

输入层与 Embedding 层

输入层接收用户 ID、物品 ID 以及可能的辅助特征（如上下文信息）。这些大多是类别型特征，取值空间大而稀疏，直接输入网络既占参数又难以学习。

Embedding 层为每个类别型特征维护一个独立的 Embedding 矩阵，把类别 ID 映射为稠密低维向量。得到的一组向量（记作 f₁, f₂, …, fₙ）既保留了每个特征的语义，又为后续的乘积层提供了可做乘法的数值表示。

乘积层：内积与外积

乘积层是 PNN 的核心创新，用来显式捕捉特征之间的交叉信息。它包含两种操作，分别生成向量和矩阵。

内积操作把两个特征向量相乘得到一个标量，对所有特征对做内积就拼成一个交叉向量 z：

ginner(fi,fj)=fi⋅fj

外积操作把两个特征向量相乘得到一个矩阵，能保留更细粒度的交叉信息：

gouter(fi,fj)=fi⊗fj

外积的代价是参数与计算量随维度平方增长。为了控制复杂度，PNN 会对两两外积的结果做降维：把所有特征对的外积矩阵叠加成一个叠加外积矩阵，从面把 O(n²) 的存储压回可控范围。选内积还是外积，就区分出 PNN 的两个变体——IPNN 与 OPNN。

隐藏层与局部全连接

乘积层的输出不会直接丢掉原始信息。PNN 先将内积部分 z 和外积部分 p 分别经过各自的局部全连接层，映射成新的向量 lz 和 lp，再把它们叠加（或拼接）后送入隐藏层。

隐藏层由多层全连接组成，每层包含一次线性变换与一个非线性激活（如 ReLU）。这样一来，模型既有乘积层给出的显式二阶交叉，又有隐藏层提供的更高阶、非线性的组合，表达能力比单纯 MLP 更强。

输出层

输出层把隐藏层的结果经 sigmoid 映射到 [0, 1]，表示预测点击概率或评分。损失函数随任务而变：点击率预估常用交叉熵，评分预测常用均方误差（MSE）。

小结

PNN 的结构可以概括为“Embedding → 乘积层 → 隐藏层 → 输出”：

  • Embedding 层：把稀疏类别特征变成稠密向量 f₁ … fₙ。
  • 乘积层：用内积（IPNN）或外积（OPNN）显式构造两两特征交叉。
  • 隐藏层：局部全连接整理交叉信号，再与原始 Embedding 一起做多层非线性变换。
  • 输出层：sigmoid 给出点击概率或评分。

它的优点是交叉方式可设计、可解释；代价是外积带来的计算开销，因此需要合理的降维处理来保证训练效率。
